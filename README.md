# Product Store

A simple product store made with HTML, CSS, and JavaScript.

## Features

* Products are fetched from the DummyJSON API
* Search products by title
* Add and remove products from favourites
* Favourite count updates automatically
* Loading messagee products are loading
* Error message if products cannot be loaded
* Responsive design for mobile and desktop

## How I Built It

I used `fetch()` and `async/await` to get the products from the API.

For search, I listen to the input field and filter the products based on their title.

For favourites, I used a JavaScript `Set` to store the IDs of favourite products.

## API Used

https://dummyjson.com/products
